# Hesap Makinesi

created by alex · Sürüm 1.2.1

Türkçe arayüzlü, işlem geçmişi ve açık/koyu tema seçenekleri bulunan masaüstü hesap makinesi.

## İndir

- **[Kurulum sihirbazını indir](Hesap-Makinesi-Kurulum.exe?raw=true)**
- [Taşınabilir uygulamayı indir](HesapMakinesi.exe?raw=true)

## Kurulum

`Hesap-Makinesi-Kurulum.exe` dosyasını çalıştırıp sihirbazı takip edin. Uygulama mevcut kullanıcı hesabına kurulur; yönetici izni istemez.

Masaüstü ve Başlat menüsü kısayolları varsayılan olarak seçilidir. İsterseniz kurulum sırasında **Windows ile başlat** seçeneğini de açabilirsiniz.

Kaldırmak için Windows'un yüklü uygulamalar listesindeki **Hesap Makinesi** kaydını kullanın. Kaldırma işlemi kişisel ayarları ve işlem geçmişini korur.

## Taşınabilir kullanım

`HesapMakinesi.exe` tek başına çalışır. Başka bir Windows bilgisayarına kopyalayabilirsiniz.

**Gereksinim:** Windows masaüstü ve .NET Framework 4.7.2 veya üzeri. Kurulum sihirbazı gerekli .NET sürümünü kontrol eder. Kurumsal bilgisayarlardaki uygulama çalıştırma ilkeleri geçerlidir.

## Doğrulama

Bu sürüm uygulama kontrollerinden ve 48 kurulum, güncelleme ve kaldırma kontrolünden geçti. İndirilen dosyaların SHA-256 değerleri [SHA256SUMS.txt](SHA256SUMS.txt) dosyasındadır.

Bu depo yalnızca hesap makinesinin kurulum dosyasını ve taşınabilir sürümünü içerir.
